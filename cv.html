Recent work, with what it showed

  • LLM inference harnessElixir · Rust · private; Python part public
    Provider routing with role-specific fallback chains, jittered retry honouring Retry-After, per-client rate limits, bounded concurrency, and token, cost and latency audit logs per call. Measured over 88 requests: 100 % success on a quota probe, 83 % in an outage probe, p95 latency 6.4 s. Cost, latency and quota visible per call.
  • gemini-gateElixir / Phoenix · private
    A credential service in front of the Gemini API: authenticated retrieval, constant-time token comparison, atomic credential replacement, deployed under Caddy and systemd. Enforced boundaries around agents, not prompt rules.
  • tidy-harnessSwift · public
    A verifier for agent behaviour: rules as data, a pure deterministic lens over session logs, and a Babashka reference that must agree with the Swift core exactly before a number is believed. They agree on 151 real sessions. Two implementations, one answer, or no answer.
  • pocketPWA pipeline · live, code private
    Eighteen installable, offline-first web apps behind one pipeline: a machine-checked rule set (offline cache, update banner, safe-area, no network on the critical path), content-hash service-worker versions, and a deploy that verifies the live URLs from outside. End-to-end delivery, build to verified deploy.
  • co-loopprotocol · public
    A fork-based protocol for parallel agentic work: several agents on one codebase without stepping on each other's files, and clean integration afterwards. How I run more than one coding agent at once.
  • dissemblage.artten interactive pieces · live
    First-person rooms in hyperbolic 3-space, an aperiodic binary tiling, generative card decks that compose a system prompt or an AGENTS.md from twenty choices. Each is one HTML file with no build step. Craft, and geometry, in public.
  • topo-sonifyRust · research prototype, Apr–Jul 2026
    Persistent homology, Hodge theory and Morse theory mapped to sound. The mathematical core was checked against known invariants (β(S²) = (1,0,1), χ = 2) before any audio code; stopped after the WASM build. Applied-mathematics depth behind the engineering.
